# 前端更新說明

## 需要更新的文件

### 1. utils/api.js - 添加驗證碼相關接口

在現有的 api.js 文件中添加以下方法：

```javascript
/**
 * 獲取驗證碼
 */
export function getCaptcha() {
	return request('/file/captcha', 'GET')
}

/**
 * 根據取件碼獲取文件信息（帶驗證碼）
 */
export function getFileInfoWithCaptcha(pickupCode, captchaId, captchaCode) {
	return request('/file/info/' + pickupCode, 'POST', {
		captchaId: captchaId,
		captchaCode: captchaCode
	})
}
```

### 2. pages/download/download.vue - 更新下載頁面

需要添加：
- 驗證碼輸入框
- 響應式設計
- 美化界面
- 安全提示

### 3. 樣式優化

所有頁面需要添加響應式設計，確保在手機、平板、電腦上都能正常顯示。

## 主要改進

1. **隱私保護**：
   - 添加驗證碼驗證
   - IP限制和嘗試次數限制
   - 訪問記錄

2. **界面美化**：
   - 現代化設計
   - 漸變背景
   - 卡片式布局
   - 動畫效果

3. **響應式設計**：
   - 使用 rpx 單位（小程序）
   - 使用 rem/vw 單位（H5）
   - 媒體查詢適配不同屏幕
