# 隱私保護功能說明

## 已實現的安全功能

### 1. 驗證碼保護
- **功能**：在查詢文件信息時需要輸入驗證碼
- **實現**：4位數字驗證碼，5分鐘有效期
- **位置**：`SecurityService.generateCaptcha()` 和 `verifyCaptcha()`

### 2. IP限制
- **失敗嘗試限制**：同一IP在15分鐘內失敗5次將被鎖定
- **嘗試頻率限制**：同一IP在10分鐘內最多嘗試20次
- **實現**：`SecurityService.isIpLocked()` 和 `isAttemptLimitExceeded()`

### 3. 訪問記錄
- **功能**：記錄所有取件碼驗證嘗試
- **記錄內容**：IP地址、取件碼、嘗試時間、是否成功、用戶代理
- **數據表**：`access_attempt`

### 4. 安全配置
在 `application.properties` 中可以配置：
```properties
# 最大失敗嘗試次數
security.max-failed-attempts=5
# IP鎖定時長（分鐘）
security.lockout-duration-minutes=15
# 嘗試時間窗口（分鐘）
security.attempt-window-minutes=10
```

## 數據庫更新

需要執行以下SQL創建新表：

```sql
CREATE TABLE access_attempt (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    ip_address VARCHAR(45) NOT NULL,
    pickup_code VARCHAR(6),
    attempt_time DATETIME NOT NULL,
    success TINYINT(1) NOT NULL DEFAULT 0,
    user_agent VARCHAR(500),
    INDEX idx_ip_address (ip_address),
    INDEX idx_attempt_time (attempt_time),
    INDEX idx_success (success),
    INDEX idx_ip_time (ip_address, attempt_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

或者執行更新後的 `database/init.sql` 腳本。

## API變更

### 新增接口

1. **獲取驗證碼**
   - `GET /api/file/captcha`
   - 返回：`{ captchaId, captchaCode, expiresIn }`

2. **查詢文件信息（帶驗證碼）**
   - `POST /api/file/info/{pickupCode}`
   - 請求體：`{ captchaId, captchaCode }`
   - 注意：原來的 GET 方法仍然保留以兼容舊版本

### 接口變更

- `getFileInfo()` 現在會記錄訪問嘗試並進行IP檢查
- `downloadFile()` 現在會記錄訪問嘗試並進行IP檢查

1. **更新數據庫**：執行 `database/init.sql` 創建新表
2. **重啟後端**：重新啟動Spring Boot應用
3. **更新前端**：按照 `前端代碼示例` 中的代碼更新前端文件
4. **測試功能**：測試驗證碼、IP限制等功能

## 注意事項

1. 驗證碼存儲在內存中，重啟服務會丟失（生產環境建議使用Redis）
2. IP地址從HTTP請求頭中提取，如果使用反向代理需要配置正確的Header
3. 訪問記錄會持續增長，建議定期清理舊記錄
